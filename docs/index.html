Why UniView?

Everything you need only a <UniView /> away.

🧩

Plugin Architecture

Decoupled renderer plugins — each format loads only when needed. Extend with your own custom renderers via the PluginSystem API.

⚡

GPU-Accelerated CAD

DWG and DXF files render via Three.js WebGL with geometry batching, instanced rendering, and smooth pan/zoom controls.

🧵

Web Workers & WASM

All file parsing runs off the main thread. DWG uses WebAssembly (libredwg-web). Your UI never freezes.

📄

Virtual Rendering

PDF pages load on demand via IntersectionObserver. XLSX uses virtual row rendering. Handles thousands of pages/rows effortlessly.

🎨

Annotations & Markup

Built-in SVG annotation layer with pen, highlight, arrow, rectangle, and text tools. Export annotations as JSON.

🌙

Dark Mode & Theming

Light, dark, and auto (OS preference) themes out of the box. CSS custom properties for full customization.

📦

Tiny Footprint

Tree-shakeable ESM + CJS dual output. Only import what you use. Formats you don't need are never downloaded.

🔑

Full TypeScript

Built with strict TypeScript. Complete type definitions shipped in the package. IntelliSense for every prop and hook.

🚫

Zero Backend

Everything runs in the browser. No server, no API keys, no upload required. Works offline after first load.

Installation

npm install uniview

Peer dependencies: React 18+ and React-DOM 18+.

npm install react react-dom

Quick Start

Minimal — just pass a file

import { UniView } from 'uniview';

function App() {
  return <UniView file="./drawing.dxf" />;
}

Full configuration

import { UniView } from 'uniview';
import type { DocumentInfo, ViewerError } from 'uniview';

function Viewer({ file }: { file: File }) {
  return (
    <UniView
      file={file}
      theme="dark"
      layout="continuous"
      toolbar={true}
      sidebar={true}
      annotations={true}
      initialPage={1}
      initialZoom="fit"
      onLoad={(info: DocumentInfo) => console.log('Loaded:', info)}
      onError={(err: ViewerError) => console.error(err.message)}
      onPageChange={(page) => console.log('Page:', page)}
      onZoomChange={(zoom) => console.log('Zoom:', zoom)}
    />
  );
}

Loading from URL

<UniView file="https://example.com/report.pdf" theme="light" />

Loading from ArrayBuffer

const response = await fetch('/data/plan.dwg');
const buffer = await response.arrayBuffer();
<UniView file={buffer} format="dwg" />

Hooks

UniView provides hooks for headless integration and programmatic control.

useViewer()

Main control hook — combines page navigation, zoom, layers, and sidebar.

import { useViewer } from 'uniview';

function Controls() {
  const {
    format, fileName, currentPage, totalPages, zoom,
    sidebarOpen,
    goToPage, nextPage, prevPage,
    setZoom, zoomIn, zoomOut, fitWidth, fitPage,
    toggleLayer, toggleSidebar,
  } = useViewer();

  return (
    <div>
      <span>{currentPage} / {totalPages}</span>
      <button onClick={prevPage}>Prev</button>
      <button onClick={nextPage}>Next</button>
      <button onClick={zoomIn}>Zoom In</button>
      <button onClick={zoomOut}>Zoom Out</button>
    </div>
  );
}

useZoom()

Dedicated zoom management. Min: 0.1, Max: 10, Step: 1.25×.

import { useZoom } from 'uniview';

const { zoom, setZoom, zoomIn, zoomOut, zoomTo, resetZoom, fitWidth, fitPage } = useZoom();

usePan()

Pan/drag state management with inertia (friction: 0.95).

import { usePan } from 'uniview';

const { pan, panHandlers, resetPan } = usePan();
// pan = { x, y, isDragging }
// panHandlers = { onMouseDown, onMouseMove, onMouseUp }

useFileLoader()

File loading with progress tracking.

import { useFileLoader } from 'uniview';

const { state, loadFile } = useFileLoader();
// state = { isLoading, progress, fileData, fileName, format, error }

// Load a file
await loadFile(myFile);
await loadFile('https://example.com/doc.pdf');

useAnnotations()

Annotation CRUD operations.

import { useAnnotations } from 'uniview';

const {
  annotations,    // Annotation[] for current page
  activeTool,     // 'select' | 'pen' | 'highlight' | 'arrow' | 'rectangle' | 'text'
  activeColor,    // hex color
  activeLineWidth,
  isAnnotating,
  setTool, setColor, setLineWidth,
  addAnnotation, removeAnnotation, clearAnnotations,
  exportAsJSON,   // () => string
} = useAnnotations();

Theming

UniView supports three theme modes:

  • 'light' — Light background, dark text
  • 'dark' — Dark background, light text
  • 'auto' — Follows the OS prefers-color-scheme setting
<UniView file={file} theme="dark" />

All colors use CSS custom properties for easy overriding in your own stylesheets.

CAD Features

DWG and DXF files have dedicated features:

  • WebGL Rendering — Three.js GPU-accelerated rendering with geometry batching
  • Layer Control — Show/hide layers, toggle visibility
  • Zoom — Scroll-wheel zoom (1.3× steps), fit-to-drawing
  • Pan — Space+drag or middle-click drag
  • Coordinates — Live cursor position in world coordinates
  • Keyboard Shortcuts — +/- zoom, F fit, V select mode, H pan mode

Layer control via hook

import { useLayerStore } from 'uniview';

const layers = useLayerStore(s => s.layers);
const toggleLayer = useLayerStore(s => s.toggleLayer);

layers.forEach(layer => {
  console.log(layer.name, layer.visible, layer.color);
});

toggleLayer('layer-id'); // Toggle visibility

Annotations

Enable annotation mode by setting annotations={true}:

<UniView file={file} annotations={true} />

Available tools:

  • Select — Click to move/resize existing annotations
  • Pen — Freehand drawing
  • Highlight — Semi-transparent marker
  • Arrow — Directional arrow
  • Rectangle — Bounding box
  • Text — Click to place text note

Export annotations:

import { useAnnotations } from 'uniview';

const { exportAsJSON } = useAnnotations();
const json = exportAsJSON(); // JSON string of all annotations

Plugin System

Extend UniView with custom renderers for any file format:

import { PluginSystem } from 'uniview';

PluginSystem.register({
  name: 'my-ifc-viewer',
  version: '1.0.0',
  supportedFormats: ['ifc'],
  render: async (container, file, options) => {
    // Render your custom format here
    const viewer = initMyViewer(container, file);
    return {
      destroy: () => viewer.dispose(),
      goToPage: (page) => viewer.goTo(page),
      setZoom: (zoom) => viewer.zoom(zoom),
      getInfo: () => ({ /* DocumentInfo */ }),
    };
  },
});

Types Reference

SupportedFormat

type SupportedFormat =
  | 'pdf' | 'docx' | 'doc'
  | 'xlsx' | 'xls' | 'csv'
  | 'dxf' | 'dwg'
  | 'png' | 'jpg' | 'jpeg' | 'svg' | 'tiff' | 'bmp' | 'webp'
  | 'txt' | 'rtf';

DocumentInfo

interface DocumentInfo {
  format: SupportedFormat;
  fileName: string;
  fileSize: number;
  pageCount: number;
  title?: string;
  author?: string;
  createdAt?: Date;
  modifiedAt?: Date;
  layers?: CADLayer[];   // DWG/DXF only
  sheets?: string[];     // XLSX only
}

CADLayer

interface CADLayer {
  id: string;
  name: string;
  color: string;       // Hex e.g. '#FF0000'
  visible: boolean;
  locked: boolean;
  lineType?: string;
  lineWeight?: number;
}

ViewerError

interface ViewerError {
  code: string;
  message: string;
  format?: SupportedFormat;
  originalError?: Error;
}

Annotation

interface Annotation {
  id: string;
  tool: 'select' | 'pen' | 'highlight' | 'arrow' | 'rectangle' | 'text';
  color: string;
  lineWidth: number;
  pageNumber: number;
  data: AnnotationPathData | AnnotationShapeData | AnnotationTextData;
  createdAt: Date;
}

UniViewPlugin

interface UniViewPlugin {
  name: string;
  version: string;
  supportedFormats: SupportedFormat[];
  render: (
    container: HTMLElement,
    file: ArrayBuffer,
    options: PluginOptions,
  ) => Promise<PluginInstance>;
}
